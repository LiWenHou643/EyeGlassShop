## 🎯 Project Objectives
The goal of this project is to develop an **e-commerce website for selling eyewear**, which:
- Allows customers to browse and purchase products easily
- Enables administrators to manage products and orders efficiently
- Provides a user-friendly and intuitive interface

---

## 👥 User Roles & Features

### 🔍 Guest
- View product categories
- View product details
- View store-related information (contact, policies, terms of service)
- Search for products based on preferences
- Register a new user account

---

### 👤 Customer (User)
- Log in to the system
- View product categories and product details
- Search for products
- Manage shopping cart
- Place orders and make payments
- Track order status
- Cancel orders
- Rate products
- Leave feedback

---

### 🛠️ Administrator (Admin)
- Manage products (add / edit / delete)
- Manage orders
- View sales statistics and reports
